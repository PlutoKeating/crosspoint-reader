# 多语言（I18N）

StockStick 固件只把**简体中文**编译进闪存；其它语言以 SD 卡语言包的形式在运行时加载。
这样既不占用 OTA 分区空间，又保留了完整的多语言能力。

## 组成

| 部分 | 位置 | 说明 |
|---|---|---|
| 内置目录 | `lib/I18n/translations/chinese.yaml`（`_order: "0"`） | 唯一编进固件的语言，也是 key 的权威清单 |
| 语言包源文件 | `lib/I18n/translations/*.yaml`（其余文件） | 英文及上游保留的各语言译文，只用来生成语言包 |
| 生成器 | `scripts/gen_i18n.py` | 构建前自动运行，生成 `I18nKeys.h` / `I18nStrings.*`（已 gitignore） |
| 打包器 | `scripts/build_lang_pack.py` | 把源文件编译成 `<CODE>.lang` |
| 运行时 | `lib/I18n/I18n.*`、`src/util/LanguagePacks.*` | 内置目录 + 可选语言包覆盖层 |

`gen_i18n.py` 会扫描 `src/` 与 `lib/` 中所有 `STR_*` 引用：任何被引用但 `chinese.yaml`
缺失的 key 都会让构建失败；未被引用的 key 只给出警告。

## 语言包

```bash
python3 scripts/build_lang_pack.py            # 生成全部语言包到 dist/lang/
python3 scripts/build_lang_pack.py EN DE      # 只生成指定语言
```

把 `dist/lang/<CODE>.lang` 复制到 SD 卡 `/.crosspoint/lang/`，然后在
「设置 → 系统 → 语言」中选择。设置以语言代码字符串保存在 `settings.json` 的 `language`
字段（默认 `"ZH"`）；找不到或校验失败的语言包会自动回到内置中文。

二进制格式（小端）：

```
char[4]  "SLNG"        u16 版本(1)      u16 条目数 N
char[8]  语言代码       char[32] 语言本名（UTF-8）
N × { u32 key 名 FNV-1a 哈希, u32 字符串偏移 }（按哈希排序）
以 NUL 结尾的 UTF-8 字符串区
```

- 条目按 **key 名哈希**匹配，而不是按 `StrId` 编号，所以 OTA 增删 key 后旧语言包依然可用：
  固件不认识的条目被忽略，语言包缺少的条目显示内置中文。
- 打包时，某语言缺少的 key 默认用英文补齐（`--fallback EN`，`--fallback none` 则留给内置中文）。
- 单个语言包上限 32 KiB，整体常驻 RAM（`tr()` 返回的指针指向包内数据）；目前各语言包约 4–6 KiB。
- 切换语言时持有渲染锁，避免渲染任务读到正在替换的目录。

## 字体覆盖

界面字体为 Ubuntu（含希伯来、阿拉伯表现形式、越南语补充）并以 Noto Sans SC 12 兜底；按键提示标签统一使用 Noto Sans SC 10（含 Noto Sans 拉丁/希腊/西里尔字形）。
`test/i18n_pack/BuiltinCoverageTest.cpp` 会检查内置目录中的每一个字符都能被这套字体渲染。
新增其它文字体系（例如日文假名以外的字符）时，需要先确认字体覆盖。

## 新增或修改文案

1. 在 `chinese.yaml` 中新增 `STR_*`，代码里使用 `tr(STR_*)`。
2. 在 `english.yaml` 中补充英文（它同时作为其它语言包的兜底）。
3. 其它语言可选；缺失时按上面的回落规则显示。
4. 运行 `cmake --build build/test && ctest --test-dir build/test -R 'I18n|BuiltinCatalogue'`。
