# 文案（I18N）

StockStick 固件只有一种界面语言：**简体中文**，编译进闪存。2.7.5 起没有 SD 卡语言包、
没有语言选择页，也没有从右到左（RTL）文字支持。

| 部分 | 位置 | 说明 |
|---|---|---|
| 内置目录 | `lib/I18n/translations/chinese.yaml`（`_order: "0"`） | 唯一编进固件的文案，也是 key 的权威清单 |
| 英文参考 | `lib/I18n/translations/english.yaml` | 只作翻译参考，不进固件；生成器会报告它缺少或多出的 key |
| 生成器 | `scripts/gen_i18n.py` | 构建前生成 `I18nKeys.h`、`I18nStrings.*`（已忽略，不入库） |
| 运行时 | `lib/I18n/I18n.*` | `tr(STR_*)` 直接返回内置文案 |

代码里引用了、但 `chinese.yaml` 没有的 key 会让构建失败；从未被引用的 key 会给出警告，
应当删掉。

## 字体覆盖

界面字体为 Ubuntu（拉丁、希腊、西里尔及越南语补充）并以 Noto Sans SC 12 兜底；按键提示
标签统一使用 Noto Sans SC 10（含 Noto Sans 拉丁/希腊/西里尔字形）。2.7.5 起内置字体不再
包含希伯来文和阿拉伯文。`test/i18n/BuiltinCoverageTest.cpp` 会检查内置目录中的每一个字符
都能被这套字体渲染。

## 新增或修改文案

1. 在 `chinese.yaml` 中新增 `STR_*`，代码里使用 `tr(STR_*)`。
2. 在 `english.yaml` 中补上英文参考。
3. 运行 `cmake --build build/test && ctest --test-dir build/test -R 'I18n|BuiltinCatalogue'`。
